# GlucoSense AI

GlucoSense AI is a machine learning-powered diabetes risk assessment web application built with Python and Streamlit.

## Features

- Diabetes risk prediction
- Risk probability analysis
- Explainable AI insights
- Patient summary
- Downloadable patient reports
- Interactive risk visualization

## Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib

## Model

Logistic Regression

## Disclaimer

This application is for educational purposes only and does not provide medical diagnosis.
